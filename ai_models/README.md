# AI_Models
- The purpose of this folder is to mock the functionality at the AI provider level.
- In the current implementation where data is generated, this only means storing the model's names and labels.
- However, in a production environment this is where you would put code to interact with the AI model (ChatGPT, Gemini, etc).
    - Then data is sent to the data_evaluation stage where the text is used to generate metrics (policyCompliance, etc).

- I've included 2 example files Chat_5.2.json and Gemini_3.json
